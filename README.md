# Amazon-Clone-Project
A static Amazon homepage clone built using only HTML and CSS. This project is a hands-on exercise to develop web design and layout skills by replicating the core structure and look of Amazon’s homepage.

Learning Outcomes
1) Mastery of HTML for structuring complex layouts.
2) Advanced CSS techniques for styling, responsive design, and layout management.
3) Experience in mimicking real-world, production-grade web interfaces.
